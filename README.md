# LunarCapital 🚀

LunarCapital is a revolutionary **trading co-pilot dashboard** designed to transform how traders interact with market data. Hosted at **[milky-way.space](https://milky-way.space)**, this Django-powered application acts as a contextual trading assistant that **reduces cognitive load** and **enhances decision-making** through intelligent data synthesis.

---

## 🌌 Features

### 🛰 Main Dashboard

* **Copilot** – Your intelligent trading assistant.
* **Screener** – Discover trading opportunities with advanced filters.

### 📊 Markets

* **Forex** – Live FX insights and analytics.
* **Stocks** – Track equity markets with clarity.
* **Crypto** – Stay ahead with cryptocurrency trends.

### 🔎 Research & Tools

* **News** – Market-moving news aggregation.
* **Financial Calendar** – Key economic events at a glance.
* **Strategy Tester** – Validate and backtest your trading ideas.

### 📈 Performance & Metrics

* **CSV Analysis** – Upload trade logs to generate performance metrics and actionable insights.

### 📝 Productivity

* **Trade Planner** – Organize and structure your trading plans.
* **Trading Journal** – Keep a log of trades and reflections.
* **Konnekt** – Real-time chat for collaboration.
* **Todo List** – Stay on top of your trading workflow.

### 🎭 Fun Stuff

* **Shenanigans** – Lighthearted features to balance the intensity of trading.

---

## 🛠 Tech Stack

* **Backend:** Django (Python)
* **Frontend:** Bootstrap, HTML5, CSS3, JavaScript
* **Database:** PostgreSQL
* **Hosting:** Deployed at [milky-way.space](https://milky-way.space)

## 🚀 Getting Started

### Prerequisites

* Python 3.10+
* Django 5+
* Virtual environment recommended

### Installation

```bash
git clone https://github.com/yourusername/lunarcapital.git
cd lunarcapital
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Visit: `http://127.0.0.1:8000/`
